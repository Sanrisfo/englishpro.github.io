# englishpro.github.io

![alt text](<Captura de pantalla 2025-09-26 000009.png>)

EnglishPro es una app para usuarios intermedios y avanzados que ofrece preguntas tipo IELTS y TOEFL, junto con módulos especializados para mejorar habilidades y prepararse para exámenes internacionales.

# Arquitectura Seleccionada: Modelo-Vista-ViewModel (MVVM)

Se ha seleccionado el patrón MVVM para la arquitectura de la aplicación debido a sus ventajas en términos de separación de responsabilidades y facilidad de mantenimiento. La separación entre la Vista, el ViewModel y el Modelo facilita la escalabilidad del proyecto y permite pruebas más claras de cada componente.

# Lenguaje Seleccionado: Dart
Se eligió **Dart** como lenguaje de programación por las siguientes razones:

- Es el lenguaje oficial de Flutter, lo que asegura una **integración nativa** con el framework.  
- Ofrece una **sintaxis clara y fácil de aprender**, ideal para equipos en formación.  
- Está optimizado para aplicaciones móviles, lo que se traduce en un **alto rendimiento y fluidez** en dispositivos Android e iOS.  
- Permite **programación reactiva y asincrónica**, clave en aplicaciones modernas con múltiples interacciones en tiempo real.

# Framework Seleccionado: Flutter_
Se seleccionó **Flutter** como framework de desarrollo, con la siguiente justificación:

- Permite crear **aplicaciones multiplataforma** (Android, iOS, Web, Desktop) desde un único código base.  
- Cuenta con un sistema de **widgets altamente personalizable**, lo que facilita el diseño de interfaces modernas y atractivas.  
- Se integra perfectamente con el patrón **MVVM**, ya que facilita la gestión del estado y el binding de datos.  
- Garantiza una **gran comunidad y soporte continuo**, asegurando documentación abundante y librerías de terceros para extender sus funcionalidades.
