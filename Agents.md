## 🎯 Objetivo del Proyecto

Desarrollar una **aplicación móvil educativa** para estudiantes de inglés de **nivel intermedio y avanzado** que necesitan:

- ✅ Prepararse para exámenes internacionales (TOEFL, IELTS)
- ✅ Mejorar habilidades comunicativas en contextos profesionales
- ✅ Practicar inglés en situaciones cotidianas reales
- ✅ Recibir retroalimentación de docentes expertos

### Propuesta de Valor

- **Contenido multimedia interactivo**: Audio, video, texto, imágenes
- **Evaluación de 4 habilidades**: Writing, Speaking, Listening, Reading
- **Retroalimentación personalizada**: Automática y manual por docentes
- **Progreso medible**: Sistema de seguimiento diferenciado por curso
- **Modelo freemium**: Acceso escalable según necesidades del usuario

## 📚 Módulos Principales

### 1. TOEFL (Test of English as a Foreign Language)

- **Formato**: Preguntas estilo examen oficial
- **Contenido**: Teoría, estrategias, tips de preparación
- **Progreso**: Medido por porcentaje (0-100%)
- **Habilidades**: Writing, Speaking, Listening, Reading
- **Características**:
    - Cuestionarios cronometrados
    - Simulación de experiencia de examen real
    - Explicaciones detalladas de respuestas

### 2. IELTS (International English Language Testing System)

- **Formato**: Preguntas estilo examen oficial
- **Contenido**: Teoría, estrategias, tips de preparación
- **Progreso**: Medido por porcentaje (0-100%)
- **Habilidades**: Writing, Speaking, Listening, Reading
- **Características**:
    - Cuestionarios cronometrados
    - Diferentes niveles de dificultad
    - Recursos complementarios

### 3. Business English

- **Formato**: Estilo Rosetta Stone (inmersivo, visual, secuencial)
- **Enfoque**: Inglés corporativo y profesional
- **Progreso**: Secuencial por módulos completados
- **Contenido práctico**:
    - Redacción de CV profesionales
    - Emails corporativos
    - Preparación para entrevistas de trabajo
    - Presentaciones y reuniones
    - Negociación y networking

### 4. English in Action

- **Formato**: Estilo Rosetta Stone (inmersivo, visual, secuencial)
- **Enfoque**: Inglés para situaciones cotidianas reales
- **Progreso**: Secuencial por módulos completados
- **Contenido práctico**:
    - Conversaciones en restaurantes
    - Viajes y turismo
    - Compras y servicios
    - Interacciones sociales
    - Emergencias y situaciones comunes

## 💳 Sistema de Planes

### Plan Freemium (Gratis)

- ✅ 1 pregunta por tipo de habilidad
- ✅ Acceso limitado a materiales educativos
- ✅ Retroalimentación automática
- ❌ Sin sesiones en vivo
- ❌ Sin simulacros completos

### Plan Básico

- ✅ 3 preguntas por tipo de habilidad
- ✅ Acceso completo a materiales educativos
- ✅ Retroalimentación automática
- ❌ Sin sesiones en vivo
- ❌ Sin simulacros completos

### Plan Pro

- ✅ 5 preguntas por tipo de habilidad
- ✅ Acceso completo a todos los materiales
- ✅ Retroalimentación automática y manual
- ❌ Sin sesiones en vivo
- ❌ Sin simulacros completos

### Plan Premium

- ✅ 5 preguntas por tipo de habilidad
- ✅ Acceso completo a todos los materiales
- ✅ Retroalimentación automática y manual prioritaria
- ✅ 5 sesiones en vivo con docentes (externo)
- ✅ 2 simulacros completos (externo)

**Nota**: Las sesiones en vivo y simulacros se coordinan externamente (WhatsApp, Zoom, etc.) pero se controlan desde la app.

## 🗄️ Base de Datos

### Diseño Conceptual

La base de datos cuenta con **16 tablas** interconectadas que manejan toda la lógica del negocio.

### Relaciones Clave

```
Usuarios → Planes (muchos a uno)
Usuarios → Docentes (uno a uno condicional)
Cursos → Habilidades (uno a muchos)
Habilidades → Preguntas (uno a muchos)
Habilidades → Materiales_Estudio (uno a muchos)
Cuestionarios ↔ Preguntas (muchos a muchos)
Usuarios → Respuestas_Usuario → Preguntas
Usuarios → Progreso_Usuarios → Cursos
Docentes → Retroalimentacion_Docente → Respuestas_Usuario
Usuarios → Pagos → Planes
Usuarios → Beneficios_Usuario
Usuarios → Notificaciones
```

### Características Especiales

#### Preguntas Multimedia

Las preguntas pueden contener:

- Texto plano
- Audio (URL Firebase Storage)
- Video (URL Firebase Storage)
- Imágenes (URL Firebase Storage)
- Combinaciones múltiples

#### Tipos de Respuestas

1. **Selección múltiple**: Tabla Opciones_Respuesta
2. **Texto abierto** (Writing): Campo Texto_Ensayo
3. **Grabación de audio** (Speaking): Campo URL_Grabacion

#### Sistema de Progreso Diferenciado

- **TOEFL/IELTS**: Campo `Avance_Porcentaje` (0-100%)
- **Business English/English in Action**: Campo `Modulos_Completados` (entero secuencial)

#### Control de Acceso por Plan

- Validación en backend de límites de preguntas según plan
- Bloqueo de contenido premium para usuarios freemium/básico
- Actualización automática de permisos tras cambio de plan

- ✅ Requisitos educativos claramente definidos desde el inicio
- ✅ Formatos de exámenes TOEFL/IELTS estandarizados y estables
- ✅ Equipo pequeño (6 personas) con comunicación directa

1. Análisis de Requisitos (Completado)

   └── Integración con Firebase

4. Pruebas (Sprint 5)
   └── Pruebas unitarias

   └── Pruebas de aceptación

5. Despliegue (Sprint 6)

   └── Documentación final

   └── Corrección de bugs

## 📏 Reglas de Negocio Críticas

### Usuarios y Autenticación

1. ✅ Un email = una cuenta única (no duplicados)
2. ✅ Contraseñas hasheadas con bcrypt
3. ✅ Sesiones gestionadas con JWT tokens
4. ✅ Verificación de email obligatoria (Firebase Auth)

### Acceso a Contenido

1. ✅ Acceso estrictamente según plan activo
2. ✅ Límites de preguntas por tipo según plan:
    - Freemium: 1 pregunta
    - Básico: 3 preguntas
    - Pro: 5 preguntas
    - Premium: 5 preguntas + beneficios
3. ✅ Solo Premium accede a sesiones en vivo y simulacros
4. ✅ Bloqueo de contenido superior hasta completar requisitos previos

### Progreso y Evaluación

1. ✅ Progreso TOEFL/IELTS: medido en porcentaje (0-100%)
2. ✅ Progreso Business/Action: medido en módulos completados
3. ✅ Datos de usuario y progreso NO modificables por estudiantes
4. ✅ Solo docentes pueden crear/modificar contenido educativo
5. ✅ Retroalimentación automática para multiple choice
6. ✅ Retroalimentación manual docente para Writing/Speaking

### Monetización

1. ✅ Pago procesado antes de activar plan
2. ✅ Vigencia de suscripción controlada por fechas
3. ✅ Degradación automática a Freemium si suscripción expira
4. ✅ Historial completo de pagos registrado

### Limitaciones

1. ❌ No otorga certificaciones oficiales (solo preparación)
2. ❌ No incluye registro oficial en TOEFL/IELTS
3. ❌ Sesiones en vivo y simulacros coordinados externamente
4. ❌ No integración con plataformas oficiales de exámenes

```bash
# 1. Instalar Flutter

flutter --version  # Verificar instalación

# 2. Instalar Dart

# Descargar de: https://www.postgresql.org/download/

# 5. Instalar Git
git --version  # Verificar instalación
```

### Configuración de Firebase

```bash
# 1. Crear proyecto en Firebase Console
# https://console.firebase.google.com

# 2. Instalar Firebase CLI
npm install -g firebase-tools

# 3. Login
firebase login

# 4. Inicializar Firebase en el proyecto
firebase init

# 5. Descargar google-services.json
# Colocar en: android/app/google-services.json
```

### Configuración del Proyecto Flutter

```bash
# 1. Clonar repositorio
git clone https://github.com/tu-equipo/englishpro.git
cd englishpro

# 2. Instalar dependencias
flutter pub get

# 3. Configurar variables de entorno
cp .env.example .env
# Editar .env con tus credenciales

# 4. Ejecutar la app
flutter run

# 5. Ejecutar tests
flutter test
```

### Configuración del Backend

```bash
# 1. Ir al directorio del backend
cd backend

# 2. Instalar dependencias Dart
dart pub get

# 3. Configurar variables de entorno
cp .env.example .env
# Editar con credenciales de BD y Firebase

# 4. Iniciar con Docker
docker-compose up -d

# 5. Ejecutar migraciones
dart run migrations/migrate.dart

# 6. Iniciar servidor de desarrollo
dart run bin/server.dart
```

### Configuración de Base de Datos

```bash
# 1. Iniciar PostgreSQL con Docker
docker-compose up -d postgres

# 2. Conectar con pgAdmin
# Host: localhost
# Port: 5432
# Database: englishpro_db
# Username: admin
# Password: (del .env)

# 3. Ejecutar script de creación de tablas
psql -U admin -d englishpro_db -f database/schema.sql

# 4. Insertar datos de prueba
psql -U admin -d englishpro_db -f database/seed.sql
```
