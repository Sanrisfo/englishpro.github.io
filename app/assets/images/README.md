# Image Assets

## 🖼️ Archivos de Imagen para EnglishPro

Esta carpeta contiene imágenes para:
- Logos y branding
- Iconos de cursos
- Imágenes para preguntas
- Avatares y perfiles

---

## 📋 Archivos Necesarios (Mínimo)

### Branding:
1. **logo.png** - Logo de EnglishPro (512x512px)
2. **logo_small.png** - Logo pequeño (128x128px)
3. **splash_bg.png** - Fondo para splash screen

### Cursos:
4. **course_toefl.png** - Imagen para TOEFL
5. **course_ielts.png** - Imagen para IELTS
6. **course_business.png** - Imagen para Business English
7. **course_action.png** - Imagen para English in Action

### Usuarios:
8. **placeholder_user.png** - Avatar por defecto (200x200px)

### Preguntas:
9. **question_sample_1.jpg** - Imagen de ejemplo para pregunta
10. **question_sample_2.jpg** - Imagen de ejemplo para pregunta
11. **question_sample_3.jpg** - Imagen de ejemplo para pregunta

---

## ✅ Formatos Aceptados
- PNG (recomendado para logos e iconos)
- JPG (recomendado para fotos)
- WEBP
- SVG (mejor usar carpeta icons/)

---

## 📏 Especificaciones Recomendadas
- **Logos**: 512x512px, PNG con transparencia
- **Imágenes de cursos**: 800x600px o 16:9
- **Avatares**: 200x200px, círculos
- **Preguntas**: 800x600px o superior
- **Tamaño**: < 500 KB por imagen

---

## 🔍 Dónde conseguir imágenes:
- [Unsplash](https://unsplash.com)
- [Pexels](https://www.pexels.com)
- [Pixabay](https://pixabay.com)
- Crear logos en [Canva](https://www.canva.com)

---

## 💡 Tips:
- Usa imágenes de alta calidad
- Optimiza el tamaño antes de agregar
- Mantén nombres descriptivos
- Usa PNG para imágenes con transparencia
