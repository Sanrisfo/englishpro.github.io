# PDF Assets

## 📄 Archivos PDF para EnglishPro

Esta carpeta contiene materiales de estudio en formato PDF:
- Textos de lectura (Reading passages)
- Guías de gramática
- Vocabulario
- Tips de escritura

---

## 📋 Archivos Necesarios (Mínimo)

### Para Testing:
1. **toefl_reading_passage.pdf** - Pasaje de lectura estilo TOEFL
2. **grammar_guide.pdf** - Guía gramatical básica
3. **vocabulary_list.pdf** - Lista de vocabulario temático
4. **writing_tips.pdf** - Consejos de escritura académica

---

## ✅ Especificaciones
- **Formato**: PDF
- **Páginas**: 1-10 páginas
- **Tamaño**: < 5 MB por archivo
- **Texto**: Debe ser seleccionable (no escaneado)

---

## 📝 Cómo crear PDFs:
1. Escribir contenido en Google Docs o Word
2. Exportar como PDF
3. Guardar en esta carpeta

---

## 💡 Ideas de contenido:

### TOEFL/IELTS:
- Pasajes de lectura académica
- Ensayos de ejemplo

### Business English:
