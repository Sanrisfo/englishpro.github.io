# Icon Assets

## 🎨 Iconos SVG para EnglishPro

Esta carpeta contiene iconos en formato SVG para:
- Habilidades (Reading, Writing, Listening, Speaking)
- Logros y certificados
- Navegación
- Acciones

---

## ✅ Formato
- **SVG** únicamente
- Colores: Negro (#000000) o usar currentColor
- Tamaño: 24x24px o 32x32px
- Sin estilos inline (CSS externo)
